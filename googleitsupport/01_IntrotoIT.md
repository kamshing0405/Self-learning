# Introduction to IT

## What is IT?

- **Information Technology (IT)**: The use of digital technology, like computers and the internet, to store and process data into useful information
- **Computer**: A device that stores and processes data by performing calculations
- **Abstraction**: Taking a relatively complex system and simplifying it for our use (e.g., mouse, keyboard hide the complexity underneath)
- **Algorithm**: A series of steps that solves specific problems
- **Open source**: Developers let others share, modify, and distribute their software freely

## History of Computing

| Era | Technology | Description |
|-----|-----------|-------------|
| Early | Punch cards | Sequences of cards with holes to perform calculations automatically |
| 1940s | ENIAC | First general-purpose electronic computer |
| 1950s–60s | Mainframes | Large room-sized computers shared by many users |
| 1970s | Microprocessor | Entire CPU on a single chip |
| 1980s | Personal Computer (PC) | IBM PC and Apple made computers accessible to individuals |
| 1990s | Internet/WWW | Global network and the World Wide Web |
| 2000s | Mobile/Cloud | Smartphones, tablets, and cloud computing |

- **PDA (Personal Digital Assistant)**: Allowed computing to go mobile before smartphones
- **Linux OS**: One of the largest open source operating systems, used heavily in business infrastructure

## Logic Gates & Binary

### Logic Gates

Logic gates allow transistors to perform complex tasks by deciding where to send electrical signals based on logical conditions.

| Gate | Symbol | Output |
|------|--------|--------|
| NOT | ¬A | Inverts input |
| AND | A · B | 1 only if both inputs are 1 |
| OR | A + B | 1 if either input is 1 |
| XOR | A ⊕ B | 1 if inputs are different |
| NAND | ¬(A · B) | Opposite of AND |
| NOR | ¬(A + B) | Opposite of OR |
| XNOR | ¬(A ⊕ B) | 1 if inputs are the same |

Combining gates builds more complex circuits (adders, memory, processors).

### Binary System

- **Binary (Base-2)**: The language computers use — only 0s and 1s (electrical signals: off/on)
- **Bit**: A single binary digit (0 or 1)
- **Byte**: A group of 8 bits
- **Nibble**: 4 bits (half a byte)

| Unit | Size |
|------|------|
| 1 Byte | 8 bits |
| 1 Kilobyte (KB) | 1,024 bytes |
| 1 Megabyte (MB) | 1,024 KB |
| 1 Gigabyte (GB) | 1,024 MB |
| 1 Terabyte (TB) | 1,024 GB |

### Decimal vs. Binary

| Decimal (Base-10) | Binary (Base-2) |
|-------------------|-----------------|
| 0 | 0000 |
| 1 | 0001 |
| 2 | 0010 |
| 3 | 0011 |
| 4 | 0100 |
| 8 | 1000 |
| 10 | 1010 |
| 15 | 1111 |
| 255 | 11111111 |

## Character Encoding

| Standard | Description |
|----------|------------|
| ASCII | Oldest standard — English alphabet, digits, punctuation (7-bit, 128 characters) |
| UTF-8 | Most prevalent today — supports all languages and emoji (variable width, backward-compatible with ASCII) |
| UTF-16 | Used internally by Windows and Java |
| Unicode | Universal standard that UTF-8/16/32 implement |

- **Character encoding**: Assigns binary values to characters so humans can read them
- **RGB model**: Red, Green, Blue — the basic model for representing colors on screen (each channel 0–255)

## IT Support Role

An IT Support Specialist may be responsible for:

- Managing, installing, maintaining, troubleshooting, and configuring hardware and software
- Providing technical assistance to users
- Setting up workstations and network equipment
- Maintaining security and data integrity
- Documenting issues and solutions

### Support Tiers

| Tier | Description |
|------|------------|
| Tier 1 | First point of contact — basic troubleshooting, password resets |
| Tier 2 | More complex issues — escalated from Tier 1 |
| Tier 3 | Expert-level — developers, engineers, deep system issues |
