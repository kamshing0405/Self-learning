# Fire protection

# Fire protection system

To identify the `presence of a fire`
Communicate the `threat` to the authorities and occupants
To `Suppress` the fire and limit any damage

Reason for fire

- Heat, oxygen, fuel

Class of fire

- Class A
- Class B
- Class C
- Class D
- Class K

Incipient, visible smoke, Flaming Fire, intense fire

- Smoke detectors
- Heat detectors
- Flame detectors
- Multi-sensor detectors
- smoke is most used

2 types of smoke detectors

- Intelligent spot type detector
- air sampling smoke detection system

Signaling devices provide

- audible alarms
  - Horns, Bells and sirens
- visual alarms
  - Flashing lights, strobe lights

Emergency power off

fire suppression

- Fire Extinguishers
  - Fire standard
  - HFC-226ea, HFC-125/ECARO-25 and FE-25
- gaseous agents
  - Inert gases
- Water Sprinkler System
  - wet-pipe, dry-pipe, pre-action
