# Lighting

1.  Lumen (lm)
2.  Lux (lx)
3.  Candela (cd)
4.  Illuminance (lx) = Luminous flux (lm) ÷ Area (m²).
    照度 (lx) = 光束 (lm) ÷ 面積 (m²)

Standard (TIA-942)

| Area                       | Recommended Illuminance | Description                                                                       |
| -------------------------- | ----------------------- | --------------------------------------------------------------------------------- |
| Computer room              | 500 Lux                 | Ensures `clear visibility`                                                        |
| Rack Front                 | 200 – 500 Lux           | Lighting `must reach` inside racks for easy cable handling and maintenance.       |
| Electrical / Cooling Rooms | 200 – 300 Lux           | Provides `safe visibility` for maintaining switchgear and chillers.               |
| Idle / Unoccupied State    | 10 – 50 Lux             | Maintains `minimal` lighting for CCTV monitoring while maximizing energy savings. |

5. DC lighting predominantly uses `LED` fixtures

- low `heat`, low `power consumption`, `long life` 50,000h+, minimal cooling load impact

6. Lighting control

Occupancy Sensors

- Use motion sensors to implement Zoning Control

Manual Override

- For special need or failure

Generator rooms and chemical areas (e.g., battery rooms) require luminaires with appropriate IP protection ratings

- Dustproof/waterproof
- Battery rooms need explosion-proof fixtures

7. Emergency lighting

- Self-contained
- Central battery and Generator-backed
- Exit signs must remain illuminated at all times
