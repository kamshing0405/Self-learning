## Utility Power Grid

`Utility Power Grid` is the `Primary Power Source` for data centers.

- High Voltage Transmission (69kV to 765kV) From Power Plant
  - To minimize power loss
  - Power loss = I^2R
  - I = P/V (Current = Power / Voltage)
  - If using 100kV (same power, more high voltage, less current)
    - I=P/V=10,000,000/10,000=100A
    - P loss = 100^2 × 2 = 20,000W = 0.02MW
- Operates on Three-Phase AC

- Power Quality
  - Voltage Sags / Swells

<br>

Data center normally accept `HV` (High Voltage) Or `MV` (Medium Voltage)

- HV (66kV - 115kV)
- MV (11kV - 22kV)

`Utility Entrance` also known as `Point of Common Coupling` (PCC) is the `boundary` between utility and data center.

## Transformers

<br>

<img src="../image/dryandoil.webp" alt="Transformer Types">

<br>

1. Type of Transformers:

- Dry-Type Transformers
  - `Inside` the building
  - No `fire` risk
  - `Lower` efficiency
  - `Higher` maintenance

- Oil-Type Transformers
  - `Outside` the building
  - `Fire` risk
  - `Higher` efficiency
  - `Lower` maintenance

<br>

2. Three type of power transformers:

- Main Power Transformer
- Distribution Transformer
- Isolation Transformer (inside the PDU)

3. How many transformers are needed?

- Depends on `Power Capacity` and `Redundancy` Requirements
- If Hyperscale and 2N (for reference)
  - `Four` 100 MVA transformers at a new substation
  - `Ten` or more distribution transformers

4. K-Factor 13

- Handle a load profile where nearly 100% of the equipment is non-linear
- Switching Mode Power Supply, SMPS

5. Structure of transformer

`Core Components`

- Primary winding
- Secondary winding
- Magnetic Core

`Only work on AC`

- e = −N (dΦ/dt)
- Changing Magnetic Field (dΦ/dt)
- DC is a static Magnetic Field

`The Law of Proportionality`

V(p)/V(s) = N(p)/N(s)

::: tip Example
If the input voltage is `10,000V` with `1,000` turns on the primary winding, and you want an output voltage of `400V`, the secondary winding must have exactly `40` turns
:::

## Uninterruptible Power Supply

- Provide `immediate backup power` when the primary utility source fails or becomes unusable

1. Static UPS (`mainly used`)

- Key Internal Components
  - Electronic switching components
  - `Double Conversion`
    - Rectifier (AC to DC)
    - Inverter (DC to AC)
  - `Static Bypass Switch`
  - `Backup Energy` Source（DC Power, one-way flow of electrons, batteries can only store energy in a single direction）

- Normal Mode (Main Switchboard → Rectifier → Inverter → PDU)
- Stored Energy Mode (Batteries → Inverter → PDU)
- Bypass Mode (Main Switchboard → Static Bypass Switch → PDU)

### Static Bypass Switch

Direct path for utility power to the load in the event of an internal UPS failure or an output overload

```
[ Utility Power (Main Switchboard) ]
                |
       _________|__________________________
      |         | (Normal path)            |
      |    [ Rectifier  ]                  |
      |         |                          | (Other path)
      |    [ DC Link  ] <--- [batteries]   |----[ Static Bypass Switch ]
      |         |                          |           |
      |    [ Inverter  ]                   |           |
      |_________|__________________________|           |
                |                                      |
                | <--- (Power Distribution) -----------┘
                |
            [ PDU ]
                |
            [ IT Racks ]
```

2. Rotary UPS

- Key Internal Components
  - Mechanism(rotating mechanical device)
  - Mechanical `Isolation`
  - only a `short duration`
  - Alternatives to Batteries

## Redundancy

<img src="../image/redunancylevel.png" alt="RedundancyLevel">

- N+1 redundancy
  - all units typically share the load
  - if one unit fails, the remaining units pick up the load

<br>

- The A/B Feed (2N architecture)
  - PDU A and PDU B
  - STS (Static Transfer Switch) is a high-speed, solid-state device used to switch between two independent power sources (Source A and Source B)

## PDU

Hierarchy Summary

1. Facility Transformer/UPS
2. Main PDU (Voltage Transformation) (may needed)
3. Power before RPP
   - RPP (Circuit Branching)
   - Overhead Power Busways (mainly nowadays)
4. POU/Rack PDU (Final Outlet Delivery)

<br>

### Main PDU (Not Common now)

1. Voltage Transformation

- such as 208V or 240V
- recommended to place outside the computer room

<br>

### RPP (Remote Power Panel, Not Common now)

- Circuit Distribution
- Circuit Protection (Breaker)
- Power Monitoring (BCM)
- positioned at one or both ends of a row of IT equipment

`Problem`

- `space` needed
- Changes often require `new wiring` runs from the panel
- Underfloor whips can block `airflow` in raised floors

<br>

### Overhead Power Busways (Mainly used in datacenter)

<br>

<img src="../image/Busways.png" alt="Overhead Power Busways" width="500"/>

- Overhead Design
- consisting of a continuous track that runs above the equipment rows
- Tap-off Box
- Enhanced Airflow Efficiency
- Scalability & Flexibility

<br>

### Rack PDU（RPDU）

- Final Distribution
- AC Power
- Redundancy
- Overcurrent Protection
- Monitoring

1. Vertical (Zero-U)
2. Horizontal: Usually 1U or 2U in height
